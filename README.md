# 👾 Proyecto Web Interactivo: Atrapado entre sueños
 
Novela visual interactiva y videojuego web de temática retro-pixel, desarrollado como parte de un proyecto de programación frontend utilizando **Bootstrap 5**, **HTML5**, **CSS3** y **JavaScript**. La historia narra las vivencias de Rhys, un joven de cabello castaño que transita por un paisaje onírico lleno de acertijos de texto y obstáculos simbólicos para resolver un conflicto con su madre.
 
## 🚀 Características Principales
 
* **Estética Retro-Pixel:** Interfaz visual inmersiva basada en una paleta de colores oscuros personalizados (`#08090d`) y la tipografía clásica *"Press Start 2P"*.
* **Estructura Multi-página:** Navegación modular e independiente entre el índice principal, las páginas de contacto y los capítulos de la historia.
* **Diseño de Historieta Alternada:** Contenido narrativo organizado en bloques responsivos con disposición secuencial en espejo (alternando imágenes y texto).
* **Interactividad y Modales:** Componentes dinámicos integrados con Bootstrap para gestionar las acciones principales de la narrativa (como la opción de "Pedir Perdón").
* **Diseño 100% Responsivo:** Adaptado mediante el sistema de rejilla (*Grid*) de Bootstrap para garantizar una lectura y visualización óptimas en computadoras, tabletas y teléfonos celulares.
 
## 🛠️ Tecnologías y Herramientas Utilizadas
 
* **HTML5:** Estructura semántica de las páginas principales y capítulos.
* **CSS3 & Media Queries:** Estilos personalizados, efectos visuales pixelados y diseño adaptativo (*Mobile First*).
* **Bootstrap 5:** Sistema de rejilla (`Grid`), tarjetas (`cards`), contenedores fluidos y componentes de interfaz.
* **JavaScript:** Control de eventos interactivos y lógica dinámica de la aplicación.
* **Git y GitHub:** Control de versiones local mediante commits y despliegue automatizado con **GitHub Pages**.
