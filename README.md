# Proyecto de programación
## Descripción
Este proyecto consiste en una página web basada en un cuento sobre un niño llamado Rhys, quien después de tener varios problemas y discusiones con su mamá, entra en un sueño donde debe superar diferentes desafíos para poder salir. Al final, aprende una lección sobre la importancia de la familia y de reconocer sus errores.

## Objetivo general
Crear una página web sobre un cuento, utilizando programación para presentar una historia entretenida que deje una enseñanza.

## Objetivos específicos
Aplicar los conocimientos adquiridos en HTML, CSS y JavaScript.
Crear una página web con un diseño atractivo y elementos interactivos.
Transmitir un mensaje sobre la importancia de la familia y la resolución de conflictos.

## Características principales
Presentación de un cuento.
Personajes y escenarios.
Elementos interactivos.
Una historia con desafíos y un mensaje final.

## Tecnologías utilizadas
HTML
CSS
JavaScript
Visual Studio Code
Git y GitHub

## Instalación y uso
Descargar o clonar el repositorio.
Abrir la carpeta del proyecto.
Ejecutar el archivo index.html en un navegador web.
Explorar la página y seguir la historia.
